# Security and privacy

This repository's public surface is a static professional portfolio. It must contain no API keys, access tokens, credentials, private customer data, non-public research, analytics trackers, hidden collection, or unreviewed third-party embeds.

## Public-content boundary

Publish only claims and artifacts that can be supported by public evidence. Do not publish classified, controlled unclassified, export-controlled, proprietary, customer-confidential, credential, sensitive personal, AFRL-sensitive, non-public NASA, or unfinished private material.

This repository must remain standalone. Do not import GovOpportunity operational files, customer information, deployment records, private research, or another project’s Git history.

## Data collection

The published site has no forms, cookies, analytics, tracking, local storage, or server-side data processing. The public email link is handled by the visitor’s selected email application or service; the portfolio itself does not collect or store submitted information.

## Reporting

Do not include suspected sensitive content in a public Git issue. Report portfolio security or privacy concerns privately to `business@suzannehoey.com`, with only the minimum information needed to investigate safely.
